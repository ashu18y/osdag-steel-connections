# Design Verification of Steel Connections using Osdag

## Overview
This project presents the manual verification of steel connections designed using Osdag. The objective is to validate software outputs through independent calculations as per IS 800:2007.

## Work Done
- Verified multiple steel connections:
  - Beam-to-Beam Cover Plate (Bolted)
  - Beam-to-Column End Plate
  - Column-to-Column Cover Plate (Bolted)
  - Column-to-Column Cover Plate (Welded)
  - Column-to-Column End Plate (Bolted)

## Key Concepts Covered
- Bolt shear and bearing capacity
- Weld strength and stress
- Plate design
- Load amplification (IS 800 Clause 10.7)
- Prying force in end plate connections
- Long joint reduction

## Files in Repository
- `main.tex` → Final combined report
- `conn1.tex` to `conn5.tex` → Individual connection calculations
- `complete.pdf` → Final report

## Tools Used
- Osdag
- LaTeX (Overleaf)
- GitHub

## Conclusion
Manual calculations closely match Osdag outputs, validating the design methodology and highlighting key structural behavior concepts.
